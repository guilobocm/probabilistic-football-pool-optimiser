# Publication Notes

This repository presents a public, sanitised portfolio implementation and a static publication package of the Group Stage postmortem. The analytical evidence-resolution pipeline and sensitive source artefacts remain in the private audit repository. The published reports are traceable to the annotated private source tag `postmortem-gs-6.2-final` and are integrity-checked through the public package manifest. Reproducibility claims are limited to the public optimiser, sample outputs, and static report package included here.
